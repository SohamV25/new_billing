# Technology Stack

## Frontend

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui

Purpose:
Modern, scalable and reusable user interface.

## Backend

- Next.js Route Handlers / API Layer
- Better Auth
- Zod

Purpose:
Secure authentication and validated APIs.

## Database

- PostgreSQL
- Prisma ORM

Purpose:
Strong relational data model with type-safe database access.

## Data Fetching

- TanStack Query

Purpose:
Caching, synchronization and server state management.

## Forms

- React Hook Form
- Zod

Purpose:
Type-safe validation with minimal re-renders.

## Development Tools

- ESLint
- Prettier
- Git
- npm

## Deployment

- Docker (optional)
- Vercel (Frontend)
- Railway / VPS / Docker for backend if required

Every technology should have a clear purpose.

Avoid introducing additional libraries unless they solve a real problem.
