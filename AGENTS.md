# Billing Dashboard - AI Agent Rules

## Purpose

This project is a production-quality Billing Dashboard. Every implementation must follow these rules.

## Technology

- TypeScript only
- Next.js (App Router)
- Tailwind CSS
- shadcn/ui
- Prisma ORM
- PostgreSQL
- Better Auth
- TanStack Query
- React Hook Form
- Zod Validation

## General Rules

- Read README.md before starting work.
- Read IMPLEMENTATION_PLAN.md before implementing any feature.
- Never assume requirements.
- Never modify unrelated files.
- Never introduce breaking changes without approval.
- Keep components reusable.
- Prefer composition over duplication.

## Code Quality

- No `any` type.
- No inline CSS.
- No duplicated logic.
- Keep files focused and small.
- Use meaningful names.
- Follow feature-based architecture.

## Backend Rules

- Validate every request.
- Return consistent API responses.
- Handle errors gracefully.
- Never expose internal errors.
- Use database transactions where required.

## Frontend Rules

- Follow the design reference.
- Do not copy HTML directly.
- Recreate the design using our stack.
- Maintain responsive layouts.
- Prioritize accessibility.

## Documentation

Whenever a sprint finishes:

- Update project-log.md
- Update IMPLEMENTATION_PLAN.md
- Update README.md if setup changes

## Working Style

Implement one feature at a time.

Stop after completing each feature.

Wait for review before moving to the next module.
